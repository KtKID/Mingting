# 网页待派发展示与派发操作

> 归属 [feat02 手动派发待派发任务](../spec.md)
> 状态 已完成 · 2026-11-14

## ① 需求与变更

任务台网页展示待派发状态并提供派发操作：状态徽标「待派发」、列表筛选标签、任务详情的执行者选择与派发按钮；发布表单与流程文案改为新语义。

## ② 精简技术设计

`statusNames` 增加待派发标签（类型系统强制补齐）；详情弹窗按状态渲染「派发任务」区，执行者输入复用根级 `harness-options` datalist（在线执行者 + 受审计名单），派发走 `POST /api/tasks/:id/dispatch` 后依赖实时快照刷新；取消按钮状态列表放行待派发。

## ③ 测试用例与变化

ui.spec.ts 新增「中台登记 → 详情派发 → 完成」端到端用例；既有不填执行者的发布用例补填 Codex；断言待派发徽标、未指定执行者展示、派发按钮禁用态与完成后筛选计数归零。

## ④ 技术实现

`src/web/main.tsx`（状态标签、筛选、派发区、取消范围、文案）；`src/web/style.css`（`status-awaiting_dispatch` 明暗两套、`dispatch-controls` 布局）。

`npm run test:ui` Playwright 回归通过（见总验证记录）。
