# 明庭 MCP 发单工具改名

## ① 需求与变更

用户指定实际 MCP 发单工具名称为 `mcp-mingting-tool`。改动范围是服务端发现与调用的名称，以及配套 KMH 转发、命令行和用法。验收前基线为 805d345 和 [原工作区差异](../../../../reports/mcp-publish-tool-name/20261106-01/evidence/workspace-before.diff)。

## ② 精简技术设计

明庭以共享常量注册唯一发单名称，现有契约生成机制给 KMH 同步常量。发布入参、回执、会话绑定和结果订阅沿用现有服务。配套客户端调用新名称。旧 MCP 名称随本次改名退出工具列表。

## ③ 测试用例与变化

调整既有 MCP 集成测试的发现与调用断言，覆盖新名称、回执、审批以及宿主绑定。调整 KMH 两个宿主回归和离线 CLI 入口。测试使用临时任务数据。

## ④ 技术实现

明庭在 `src/server/http.ts` 通过共享常量注册新名称。KMH 转发及生成契约、已安装 CLI、示例文档、测试同步采用新名称。

## ⑤ 验证结果

明庭 70 项、KMH 2 项回归通过。独立 CLI 发单成功，60390 实际工具列表显示新名称。[测试报告](../../../../reports/mcp-publish-tool-name/20261106-01/test-report.md)
