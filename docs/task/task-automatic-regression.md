# 默认自动回归覆盖任务和审批网页

[功能归属](../APPROVALS.md#a5-默认自动回归与批次留存)

## ① 需求与变更

用户要求自动完成测试选择，并明确发布测试任务、审批和查看结果的界面操作边界。接口回放验证任务状态与落库。网页回归自动验证表单、弹窗、按钮、结果与重连。

## ② 精简技术设计

沿用 A5 的默认回归运行器和归档。加入已有的桌面与手机 Playwright 套件，审批专项保留自己的范围。默认批次须有成功的网页阶段。两套浏览器测试串行运行在隔离平台上。GitHub Actions 在 PR 和 main 更新时调用同一默认入口并归档证据。

## ③ 测试用例与变化

T1 所有审批用例通过但网页阶段缺失或失败时，默认批次失败。
T2 执行默认命令，验证后端回放、构建、桌面/手机网页及审批回放自动执行并归档。
T3 保留审批专项范围，检查 GitHub Actions 与默认命令及归档的连接。

## ④ 技术实现

默认运行器增加网页阶段。浏览器配置共享隔离假 ACP 服务。报告保留网页阶段、JSON 结果与截图，旧批次结构可继续读取。GitHub 工作流调用同一测试命令。

## ⑤ 验证结果

默认命令通过 115 项后端、20 项网页与 10 项审批回放，构建通过。桌面与手机审批用例各重复五次通过。CI 配置已校验，云端执行待推送。 [统一测试报告](../../reports/automatic-regression/20261106/test-report.md)
