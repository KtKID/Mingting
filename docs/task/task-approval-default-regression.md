# 审批默认自动回归与批次留存

> 功能：[审批 A5](../APPROVALS.md)；局部设计：②；日期：2026-11-01；状态：已完成。

## ① 需求与变更

用户本轮明确要求：回放入口可见；10条审批用例进入默认回归；双方意见、用户按钮、结果填写及保存全自动；真实录制及每次结果长期保留。沿用A4录制夹具和R1–R10，修改前正文见 `reports/approval-e2e/default-regression/APPROVALS.before.md`。

新增A5。原60390人工可见回放记录和4份真实源数据保持完整。默认 `npm test` / `npm run check` 包含单元检查、构建和全部10条浏览器审批，单独审批命令使用同一运行器。每轮创建独立批次，成功、失败和未执行均据实保存。

## ② 精简技术设计

- D1 默认命令调用专用回归运行器；顺序执行单元、构建、审批，单位用例失败后仍在构建通过时执行审批；失败汇总返回非零。浏览器、双方意见与结果验证沿用真实链路，全部10条自动操作。
- D2 每轮UUID目录保留输入录制、源记录、哈希、代码基线、分阶段日志、逐例完整任务快照/断言/截图及Playwright结果与trace。私有测试SQLite留在var同批次目录。独立批次互不覆盖，失败和中断保留；目录扫描派生历史列表，避免共享索引覆盖。
- D3 页面读取共享Zod历史及报告协议，支持选择批次、逐步截图、结果与日志；原60390记录保留直接任务链接，60391自动回归提供归档任务快照。原人工回放登记为历史批次。
- D4 任务台标题旁增加“审批回放与测试记录”入口，桌面与手机均可见。仅修改当前任务内导航和验证展示。
- 规范：R1测试工具与平台单向依赖，报告复用shared协议；R2/R3使用Zod与官方SDK，单语言；R4源录制只读，平台状态归SQLite，批次快照独立留存；R5统一批次/用例命名；R6沿用LIMITS和具名轮询配置；R7错误、退出码、中断、清理均记录。

## ③ 测试用例与变化

沿用R1–R10完整业务预期；新增自动逐例填报、归档每轮输入/结果、失败保留、两轮互不覆盖、旧人工记录兼容与历史选择。回归默认命令真实执行完整10条；再独立运行一次以验证多批次留存。入口和批次切换用真实浏览器检查，原网页回归覆盖手机。

## ④ 技术实现

`scripts/run-regression.ts`统一默认/专项运行，`scripts/approval-archive.ts`冻结输入、归档结果并恢复旧记录，`src/server/approval-history.ts`只读扫描批次。共享协议扩展批次、阶段与快照字段；HTTP提供history.json，报告增加批次选择、日志和归档快照链接。

`tests/approval-replay-ui.spec.ts`逐例自动记录真实请求、操作、全部判定和截图；Playwright使用每批独立输出目录，成功/失败均保留trace。回放子进程读取冻结输入。package默认test/check接入运行器，test:unit保留诊断；主界面入口位于发布按钮旁，手机同样可见。依赖与锁文件沿用现有版本。
