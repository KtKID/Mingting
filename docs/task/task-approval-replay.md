## ② 精简技术设计

- D1：提取只读录制夹具，复用共享协议及官方 ACP SDK；回放 ACP 子进程按实际选择返回对应录制分支，取消终止。源码与原始录制分别保存。
- D2：独立测试协调器在60390通过 MCP 发布与订阅，复用 TaskConnector；目标身份“ZCode-Replay”区分日常执行器。订阅凭据留在内存和忽略的私有目录，报告只写可见状态。
- D3：用户动作由真实浏览器按钮完成。控制命令仅触发测试发布、订阅者决定、截图记录和结果核对。十秒保留实际时长。各用例持久化到正式任务库。
- D4：同源 `/approval-tests/` 只读 HTML 查看用例矩阵、逐步截图、时间线、断言和原始来源，链接回正式任务详情；页面固定浅色，实际任务台以显式 `theme=light` 观看。本次增加链接选中任务能力，日常默认主题沿用原设置。
- R1/R4/R5：测试工具位于 scripts，协议沿用 shared，任务状态由平台 SQLite 拥有，HTML 是可重建验证快照；源数据只读。R2：共享 Zod 校验边界，ACP 用官方 SDK。R3：单语言。R6：十秒使用既有 LIMITS，轮询常量具名。R7：逐用例串行、真实裁决、终态断言、关闭临时连接器；保留日常任务与服务。

实现补充：自动重跑采用独立Playwright入口，复用同一R1–R10定义与ACP录制，方便一条命令回归。浏览器等待本机会话建立后共享请求上下文；订阅者决定时间与截止时间复用一次时间读取，消除1毫秒漂移。该补充恢复A3十秒定义，使用AR5固定时间测试；测试结果和失败原因分别保留。
